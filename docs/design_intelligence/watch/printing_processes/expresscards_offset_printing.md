## Claims

1. `t=0:13` (frame) Artwork is first split into color separations — the design
   shown fanned into per-color versions (magenta/grey planes) before any press
   geometry appears.
2. `t=0:32` (frame) Press unit anatomy: colored inking-roller trains (cyan and
   magenta groups shown) feed a **plate cylinder** (dark, carrying artwork),
   which contacts a second cylinder carrying the inked image.
3. `t=0:47` (frame, labeled) On-screen labels: "**BLANKET (OFFSET) CYLINDER**"
   and "**IMPRESSION CYLINDER**" — the sheet web runs between blanket and
   impression cylinders; printed sheets exit with the design right-reading.
   This is the offset chain: plate → blanket → paper, the transfer step the
   process is NAMED for.
4. `t=0:57` (frame) Output shown as a tall stack of identical printed sheets —
   the animation's payoff is volume: one plate setup, thousands of sheets.
5. `t=1:22` (frame) Outro promotes a companion "How to set up artwork for
   print" video — core process content ends ~1:15.

## Engine hooks

- Claim 3 completes the press-anatomy vocabulary the ink_color_systems notes
  assumed: a "plate" (INNORHINO's press-prep cost, PAPP's spot-swatch-equals-
  plate rule) is physically the plate cylinder's dressing; each ink station =
  one plate+blanket unit. The engine's "extra spot = extra plate = cost" rule
  now has its mechanism.
- Claims 1+2: separations precede the press — this is what the prepress
  emitter's CMYK/spot separation output physically becomes. Reinforces the
  declared-inks preflight rule from three prior sources.
- Claim 4 pairs with Lil Packaging's litho-vs-flexo cost logic: offset =
  high setup (plates, separations) then cheap volume — same shape as
  INNORHINO's spot-ink economics. Offset is the unit-carton default process;
  flexo the shipper default (cross-link lilpackaging_litho_vs_flexo).
