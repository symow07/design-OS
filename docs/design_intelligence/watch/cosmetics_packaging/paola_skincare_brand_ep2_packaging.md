## Claims

1. [t=0:40–1:22] Dieline reverse-engineering technique: take a real retail carton
   (Rare Beauty lip product), un-glue it, lay it flat, flatbed-scan it, and trace the
   scan with the pen tool — cut lines as solid shape, fold lines as thinner marks
   [t=2:54–3:22]. Yields both a digital mockup template and a printable dieline.
2. [t=5:04–5:46] The unfolded reference teaches panel semantics: which panels face
   front, which are sides, which tuck away, which form the lid — placement of logo and
   copy is decided by reading the physical fold, not the flat artwork.
3. [t=6:33–7:14] Realism checklist for a believable pack: barcode, shelf-life (PAO)
   symbol, cruelty-free mark, net weight, recycling mark — the mandatory-furniture
   layer that separates a real pack from a concept render.
4. [t=8:37] Glue-flap discipline: mark the glue strip visibly in the working file so
   artwork never lands on it.
5. [t=9:06–10:55] Scale validation loop: measure the physical reference box, set the
   artboard to true print size, test-print on plain paper, and overlay against the
   reference — a match proves dimensional truth before committing to cardstock.
