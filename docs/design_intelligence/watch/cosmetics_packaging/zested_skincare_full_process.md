## Claims

1. [t=1:24–2:06] Brief-generation rule: reject "hydration" as a USP — every skincare
   brand hydrates. Iterate LLM briefs until each carries distinct core values /
   philosophy; she generated ~30 named concepts before choosing "Zested" (citrus,
   energizing, morning routine).
2. [t=3:30–4:34 + frame 3:55] Moodboard before pixels: Pinterest board of acid/neon
   print ephemera. Working contrast principle: an acid color reads brighter next to a
   gray of the SAME tonal value but different chroma.
3. [t=5:36–5:56] Category ceiling: food packaging may "scream"; skincare must stay
   more practical/readable. Loudness is category-relative.
4. [t=6:16–6:56] Standout device: two adjacent panels form ONE continuous image so the
   pack reads as a 3D object on shelf — rare in the category, memorable.
5. [t=7:38–8:20] Labeling rule: the pack must state WHAT IT IS ("daily moisturizer")
   — brand-name-only fronts force guessing (shampoo? serum? toner?).
6. [t=10:05–12:31] Custom-lettering recipe for a handmade title: start from a
   handwritten font → fix cropped terminals → liquify edges wavy/uneven → make repeated
   letters (two E's) deliberately non-identical so it reads as lettering, not a font.
7. [t=15:40–16:42] Type hierarchy rule: handwritten/decorative style survives only as
   the hero title + side titles; all informational text goes in a simple, not-too-thin
   sans. Whole-pack handwriting demands a far artsier product to pull off.
8. [t=16:42–17:24] Text-side enrichment: curve the text baselines to match the pack's
   organic language — playful but still readable (flags it as a client-risk choice).
9. [t=17:24–18:07] Panel cohesion: repeat one motif (a lemon) across the "boring"
   text sides at high contrast, hovering between recognizable object and abstract
   shape; shadow added to pop the grain texture.
10. [t=13:56–14:18, 18:28–19:10] A single contrasting frame color (red) shifted the
    whole pack slightly retro/'70s — one element can retint the era-read of a design;
    accepted because it added warmth.
11. [t=19:53–20:36] Category observation: experimental design currently lives in hair
    care; skincare buyers want trustworthy over experimental — she balanced two vibrant
    hero panels against calm remaining sides.
12. [t=15:00–15:20] Tooling: exploratory pass in Photoshop (gradients, grain, liquify);
    convert to vector in Illustrator only when heading to print.
