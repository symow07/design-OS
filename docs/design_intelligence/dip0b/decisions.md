# DIP-0B decisions of record

- `DIELINE_CANDIDATE` / `LIKELY_DIELINE_STRUCTURE` — never a confirmed dieline; three outcomes with a config-driven review band.
- A thin structural stroke is NOT technical ink; a colour is excluded only when B3 typed that path technical.
- Registration is not black; `/All` never a confident artwork match; black artwork never auto-stripped.
- Six colour buckets incl. `unresolved_or_ambiguous`; unattributed process colour kept distinct from a failed spot match.
- Level-A typography only; Level B unavailable; DIP-0E is the future OCR milestone.
- Machine inference and human confirmation live in separate blocks; a batch is a review convenience, never an auto-applied decision.
- Historical designs are reference memory, not templates.
