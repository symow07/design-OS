# Add BBROSE's best work

Drop about 30 images into this folder's `files/` directory. Use your own completed designs, including decorated bottles, jars, colour cosmetics, assembled displays and cartons. PNG/JPEG is easiest to review; keep original production files elsewhere unchanged.

Fill one row per image in [reference-sheet.md](reference-sheet.md): filename, category and why it works. Add the remaining notes where known; blank means unknown. Use stable IDs HR001–HR030 and distinct filenames. Do not rename a file after filling the sheet.

These are intake files. They are not yet automatically approved, imported or passed to image generation. The next reference milestone adds validation, tagging, ranking and the same approved pack for planner and generator. You control approval and rights; no paid tagging runs just by dropping a file here.

Folder: `docs/brand/house_references/files/` at the repository root.
