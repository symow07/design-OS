## SECTION A — RULINGS

### A51. No. A named gap in an enforcement mechanism is an unenforced law.

You asked whether a proven reference detector plus a weaker gate is acceptable so long as the
gap is named. Naming it was right and it is the reason you get a clean answer instead of a
discovery three nodes from now. But the answer is no, and the reason is that the arrangement is
a member of the class it was built to catch.

Follow it through. The corpus goes green. The gate misses a corpus-covered shape. The suite
passes on a commit that introduces a class member. **A green suite is a plausible in-range
result produced from a condition the instrument could not handle** — which is 1q's definition,
word for word. The corpus-plus-weaker-gate arrangement is a `SILENT_PLAUSIBLE_FALLBACK`, sitting
inside the machinery commissioned to detect them.

It is also 1p directly: a control established on one instrument does not transfer to a different
instrument. The corpus validates the reference detector. The gate is a different instrument. The
gate is `INSTRUMENT_NOT_VALIDATED_AT_CONDITION` and its passes carry nothing.

So 1z reads as you suspected: **the corpus must run against the detector that enforces the
gate.** And the arc's third condition is therefore **not done** — Section E's distance of 49 is
understated, because it omits this. Restate the distance with the gate item in it.

### A52. The reflexive case has appeared four times. Hash it.

This arc has now built four instruments to detect the class, and every one of them was a
candidate member of the class:

1. The A38 trace instrument — an empty trace reading as "nothing fired." Flagged before build,
   guarded with a raising writer and a positive control.
2. The A43 import resolver — silently skipping an unresolvable import yields a graph that looks
   complete. **Fired live** on your first run; caught before any clear committed.
3. The A47 census tool — read `args.defaults` where the defaults were keyword-only and returned
   a false zero. **Fired live**, inside the node about census completeness, and was caught.
4. The gate/corpus split above.

Two of four fired. That is not a run of bad luck, it is a structural feature: an instrument built
to detect a class operates on exactly the inputs that class is about, so it is unusually likely to
contain one. Hash the response, because it is nearly free now that corpora exist:

> **REFLEXIVE VALIDATION.** An instrument commissioned to detect a defect class is itself a
> candidate member of that class. Before its first reading is used, it must be run against that
> class's own seeded corpus, and any failure is a defect in the instrument rather than a finding
> about the subject.

Note the retroactive warrant: had this been law, instance 3 would have been caught by
construction rather than by your attention — the corpus contains a keyword-only default, and a
census tool run against the corpus would have failed on it immediately. A rule that would have
caught a live instance is a rule earned by evidence rather than by anticipation.

### A53. The gate is a union, not a replacement — and the 194 is the artifact it needs

Do not swap the regex paths out for the AST detector. Regex may catch something AST does not —
occurrences in templates, strings, or non-Python files — and removing a detector is a
strengthening argument that could quietly be a weakening. **Compose them: the gate is the union
of both detectors, and the corpus runs against the union as composed.** 1z's requirement is that
the corpus tests the thing that gates, not that the thing that gates be any particular
implementation.

The reason the regex gate survived this long is presumably that an AST gate would go red
immediately against the existing codebase. That needs a baseline, and a baseline is an
allowlist, and under 1r an allowlist is an affirmative claim carrying the burden of
establishment. **The 194-site enumeration is exactly that baseline**, and it is established by a
competent instrument — so the audit arc has produced the artifact the gate needs in order to
exist. Anything not in the 194 is new, and the gate fails on it.

Key the baseline on something stable — file path, enclosing symbol, and shape — not on line
numbers, or the first reformat trips every entry and the gate gets disabled by whoever is
unlucky enough to be on shift.
